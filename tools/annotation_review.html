Read before labelling

Choose the original BAR-ATH_tactical.mp4. It stays on your computer. Use desktop Chrome or Edge for decoded-frame reporting. Keep sound on for foul whistles.

H = Barcelona (blue/red); A = Athletic (white); D = dead ball; X = unclear. A loose ball stays with the last team until the opponent controls it. D starts at the whistle or when the ball crosses a line; live play starts at the restart touch. Check the following play before deciding whether a goalkeeper catch was followed by a free kick.

First select the public-calibration window. Label it blind, close it, then reveal the supplied public boundaries and check differences. The public labels contain subtle foul/restart conventions; see tools/LABELLING.md. Calibration labels are excluded from all three new splits. Do not copy model predictions into these windows.

Watch a complete window, mark rough changes, then refine every change frame by frame. Put the current label at the window's first frame. Uncertain spans need an X start and a known-label start when certainty returns. The end is closed with X. Window edges censor partial possessions; keep these fixed for a reproducible split.

Space play/pause · ←/→ one frame (Shift: 5, Ctrl: 25) · H/A/D/X start a segment · U undo. Click a boundary to seek there. Delete removes the boundary at the displayed frame.

Download a JSON backup after each window. Mark reviewed only after checking all changes; this is your review record. Test labels must stay out of model fitting and model selection.
